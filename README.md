# Bitrix24 Quick Links

Браузерное расширение добавляет в левое меню Bitrix24 панель быстрых ссылок с поиском, избранным, вложенными окнами и редактором конфигурации. Интерфейс повторяет визуальные паттерны Bitrix24 и работает поверх открытой страницы портала.

> Проект не является официальным продуктом или расширением компании «1С-Битрикс».

**Актуальный выпуск:** `1.0`

**Safari Userscripts:** `1.0.4`

## Возможности

- быстрый переход к разделам Bitrix24;
- блоки, вложенные окна и многоуровневая структура ссылок;
- поиск по названиям, описаниям и вложенным кнопкам;
- избранные ссылки;
- открытие задач, сделок, счетов и смарт-процессов по ID;
- настройка свернутых блоков и кнопки «Открыть весь блок»;
- редактор блоков и кнопок с импортом и экспортом JSON;
- автоматическая, светлая и темная темы;
- открытие ссылки в текущей вкладке обычным кликом и в новой вкладке средней кнопкой мыши;
- локальное хранение конфигурации без внешнего сервера расширения.

## Установка

### Chrome и Edge

1. Скачайте и распакуйте `b24-quick-links-1.0.zip`.
2. Откройте страницу управления расширениями.
3. Включите режим разработчика.
4. Нажмите **Загрузить распакованное расширение**.
5. Выберите распакованную папку с `manifest.json`.
6. Обновите открытую вкладку Bitrix24.

Для разработки можно выбрать папку [`src/chromium`](src/chromium) напрямую.

### Яндекс Браузер

Откройте `browser://tune` и перетащите в окно файл `b24-quick-links-1.0.crx`. Браузер может запрещать локальные CRX, не опубликованные в проверенном каталоге. Отключать защиту браузера ради установки не следует; в этом случае используйте Chromium ZIP и режим разработчика, если браузер его поддерживает.

### Firefox

Неподписанный XPI предназначен для Firefox Developer Edition. Откройте `about:addons`, выберите **Установить дополнение из файла** и укажите `b24-quick-links-1.0-unsigned.xpi`.

Обычный Firefox требует подпись Mozilla. Подробности находятся в [`docs/firefox-signing.md`](docs/firefox-signing.md).

### Safari

Safari-версия работает через бесплатное расширение Userscripts и не требует ежедневной переустановки.

1. Установите Userscripts из App Store и включите его расширение в Safari.
2. Разрешите Userscripts доступ только к нужным доменам Bitrix24.
3. Скопируйте оба `.user.js` из [`releases/1.0/safari`](releases/1.0/safari) в папку `Save Location`, указанную приложением Userscripts.
4. Обновите вкладку портала.

Подробная инструкция находится в [`src/safari-userscripts/README.md`](src/safari-userscripts/README.md).

## Настройка

Пользователь может менять блоки и кнопки в интерфейсе:

1. Откройте **Быстрые ссылки**.
2. Нажмите кнопку настроек.
3. Перейдите в **Редактор ссылок**.
4. После изменений экспортируйте JSON как резервную копию.

Базовая конфигурация хранится в `settings.js` соответствующей браузерной сборки. Пользовательская конфигурация имеет приоритет над базовой.

## Данные и разрешения

Расширение получает доступ только к доменам, перечисленным в его манифесте. Оно не использует внешний сервер, аналитику и рекламные трекеры. Настройки остаются в браузере пользователя. Подробнее: [`docs/privacy.md`](docs/privacy.md).

## Разработка и проверка

Требуется Node.js 18 или новее.

```bash
npm install
npm test
npm run test:ui
```

`npm test` проверяет синтаксис, открытие вкладок в фоновом процессе и сборку Safari. Визуальный smoke-тест требует установленный Google Chrome или совместимый Chromium.

## Структура репозитория

```text
src/chromium/           исходники Chrome, Edge и Яндекс Браузера
src/firefox/            исходники Firefox
src/safari-userscripts/ Safari-адаптер и инструкция Userscripts

docs/                   документация, приватность и заметки о выпуске

```

Приватные ключи, локальные резервные копии и пользовательские JSON-настройки в репозиторий не добавляются.
