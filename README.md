# Bitrix24 Quick Links Extension

Расширение добавляет в левое меню Bitrix24 панель быстрых ссылок с интерфейсом в стиле портала.

Актуальная версия: **1.0**.

## Возможности

- быстрый переход к разделам Bitrix24;
- блоки, вложенные окна и многоуровневая структура ссылок;
- поиск по названиям, описаниям и вложенным кнопкам;
- избранные ссылки;
- открытие задач, сделок, счетов и смарт-процессов по ID;
- редактор блоков и кнопок с импортом и экспортом JSON;
- светлая, темная и автоматическая темы;
- открытие ссылки в текущей вкладке обычным кликом и в новой вкладке средней кнопкой мыши.

## Установка

### Chrome и Edge

1. Распакуйте `b24-quick-links-1.0.zip`.
2. Откройте страницу управления расширениями.
3. Включите режим разработчика.
4. Нажмите **Загрузить распакованное расширение**.
5. Выберите распакованную папку, содержащую `manifest.json`.

Для разработки можно сразу выбрать папку `src/chromium`.

### Яндекс Браузер

Откройте `browser://tune` и перетащите в окно файл `b24-quick-links-1.0.crx`. Браузер может блокировать локальные CRX, не опубликованные в проверенном каталоге. Отключать защиту браузера ради установки не следует.

### Firefox

Неподписанный XPI предназначен для Firefox Developer Edition. Откройте `about:addons`, выберите **Установить дополнение из файла** и укажите `b24-quick-links-1.0-unsigned.xpi`.

Обычный Firefox требует подпись Mozilla. Инструкция находится в [`docs/firefox-signing.md`](docs/firefox-signing.md).

### Safari без Apple Developer Program

Safari-вариант работает через бесплатный менеджер Userscripts и не требует ежедневной переустановки. Сборка поддерживает основной, тестовый и dev-порталы на доменах OSTEC и Selectica.

1. Установите Userscripts из App Store и включите его расширение в Safari.
2. Разрешите доступ к шести доменам из раздела «Поддерживаемые порталы».
3. Скопируйте оба файла из `releases/1.0/safari` в папку `Save Location`, показанную приложением Userscripts.
4. Обновите вкладку портала.

Подробности находятся в [`src/safari-userscripts/README.md`](src/safari-userscripts/README.md).

## Структура репозитория

```text
src/chromium/          исходники Chrome, Edge и Яндекс Браузера
src/firefox/           исходники Firefox
src/safari-userscripts/описание Safari-адаптера Userscripts
releases/1.0/          готовые пакеты версии 1.0
docs/                  документация и заметки о выпуске
tools/                 упаковщик CRX3 и проверки
```

Закрытые ключи, локальные резервные копии и пользовательские настройки в репозиторий не добавляются.

## Настройка

Базовые блоки и ссылки задаются в `settings.js` соответствующей браузерной сборки. Пользователь может менять их прямо в расширении через **Настройки -> Редактор ссылок** и переносить конфигурацию через JSON.

## Проверка исходников

```bash
npm install
npm run build:safari
npm run test:syntax
npm run test:background
npm run test:ui
```

Визуальный smoke-тест требует установленный Google Chrome или путь к совместимому Chromium.

## Хранение данных

Расширение не отправляет пользовательские настройки на внешние серверы. Chromium-сборка использует локальное хранилище расширения. Firefox-сборка использует `localStorage` текущего портала и не создает фоновую страницу.

## Производительность

- окно Safari полностью удаляется из DOM после закрытия;
- во время поиска исходные кнопки временно удаляются из DOM и не дублируют результаты;
- настройки состояния блоков и кнопки «Открыть весь блок» сохраняются локально для каждого браузера.
