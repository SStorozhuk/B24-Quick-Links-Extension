# Bitrix24 Quick Links

Браузерное расширение добавляет в левое меню Bitrix24 панель быстрых ссылок с поиском, избранным, вложенными окнами и редактором конфигурации. Оно работает с облачными и коробочными порталами на произвольных HTTPS-доменах.

> Проект не является официальным продуктом или расширением компании «1С-Битрикс».

**Актуальная версия:** `1.1.0`

## Возможности

- однократная активация на открытом портале без сборки под конкретный домен;
- быстрый переход к разделам Bitrix24;
- базовый набор ссылок для новой установки;
- блоки, вложенные окна и многоуровневая структура;
- поиск, избранное и открытие сущностей по ID;
- редактор кнопок с импортом и экспортом JSON;
- светлая, темная и автоматическая темы;
- обычный клик открывает ссылку в текущей вкладке, средний — в новой;
- отдельная пользовательская конфигурация для каждого активированного портала;
- локальное хранение без внешнего сервера, аналитики и рекламы.

## Поддерживаемые порталы

Chromium- и Firefox-версии не содержат фиксированного списка адресов. Пользователь активирует расширение отдельно на каждом нужном HTTPS-портале. Перед активацией расширение проверяет наличие интерфейса Bitrix24 с левым меню.

Поддерживаются, например:

- облачный портал `https://company.bitrix24.ru/`;
- коробочный портал `https://crm.company.ru/`;
- основной, тестовый и dev-порталы на разных доменах.

## Установка и активация

### Chrome, Edge и Яндекс Браузер

1. Скачайте и распакуйте Chromium ZIP.
2. Откройте страницу управления расширениями и включите режим разработчика.
3. Нажмите **Загрузить распакованное расширение** и выберите папку с `manifest.json`.
4. Войдите в Bitrix24 и откройте страницу с левым меню.
5. Нажмите значок расширения и выберите **Активировать на портале**.
6. Подтвердите доступ только к открытому адресу.

Для второго портала повторите шаги 4–6. Для разработки можно выбрать папку [`src/chromium`](src/chromium) напрямую.

### Firefox

Неподписанный XPI предназначен для Firefox Developer Edition. Установите его через `about:addons`, затем откройте портал и активируйте адрес по значку расширения. Обычный Firefox требует подпись Mozilla; подробности находятся в [`docs/firefox-signing.md`](docs/firefox-signing.md).

### Safari

Safari-версия работает через бесплатное расширение Userscripts и не требует ежедневной переустановки.

1. Установите Userscripts из App Store и включите расширение.
2. Скопируйте оба `.user.js` из [`releases/1.1/safari`](releases/1.1/safari) в папку `Save Location` приложения Userscripts.
3. На нужном портале разрешите Userscripts доступ к этому сайту.
4. Обновите страницу с левым меню Bitrix24.

Подробная инструкция: [`src/safari-userscripts/README.md`](src/safari-userscripts/README.md).

## Базовая конфигурация

Новая установка содержит пять блоков:

- **Открыть по ID** — сделка, счет и задача;
- **CRM** — лиды, сделки, клиенты, счета и каталог;
- **Работа** — лента, задачи, календарь и диск;
- **Сотрудники** — сотрудники, структура, учет времени и видеоконференции;
- **Настройки** — основные страницы настройки CRM и бизнес-процессов.

Внутренние ссылки хранятся как пути вида `/crm/deal/kanban/` и автоматически открываются на текущем портале. Организационные ID направлений, групп, списков и смарт-процессов в базовую конфигурацию не входят.

## Настройка и перенос данных

Откройте **Быстрые ссылки → Настройки → Редактор ссылок**, чтобы изменить набор кнопок. Конфигурации разных порталов хранятся раздельно. Тема остается общей для расширения.

Старые настройки версии `1.0` переносятся при первом запуске на прежнем портале. Внутренние абсолютные ссылки преобразуются в относительные. Импорт старого JSON также поддерживается.

Порядок настройки стартового набора описан в [`docs/customization.md`](docs/customization.md).

## Данные и разрешения

При установке расширение не получает постоянный доступ ко всем сайтам. После действия пользователя браузер предоставляет доступ только к выбранному HTTPS-порталу. Открытие новых вкладок ограничено доменом страницы, из которой пришла команда.

Подробнее: [`docs/privacy.md`](docs/privacy.md).

## Разработка и проверка

Требуется Node.js 18 или новее.

```bash
npm install
npm test
npm run test:ui
```

Проверки охватывают синтаксис, универсальную конфигурацию, активацию портала, безопасность открытия вкладок, Safari-сборку и полный интерфейсный сценарий.
