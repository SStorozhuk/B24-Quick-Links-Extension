# Подписание Firefox-расширения

Обычный Mozilla Firefox устанавливает постоянные расширения только с подписью Mozilla. В репозитории хранится неподписанный пакет:

`releases/1.0/firefox/b24-quick-links-1.0-unsigned.xpi`

## Подготовка скрытого дополнения

1. Откройте [Mozilla Add-on Developer Hub](https://addons.mozilla.org/developers/).
2. Войдите в учетную запись Mozilla.
3. Создайте новое дополнение.
4. Выберите распространение **On your own** / **Самостоятельно**.
5. Загрузите `b24-quick-links-1.0-unsigned.xpi`.
6. Дождитесь проверки и скачайте подписанный XPI.

Подписанный пакет можно устанавливать в обычный Firefox без публикации дополнения в открытом каталоге.

## Обновление

При следующем выпуске необходимо сохранить Gecko ID `b24-quick-links-v2@ostec-group.local`, увеличить версию в `src/firefox/manifest.json`, собрать новый XPI и загрузить его как новую версию существующего дополнения.

Не добавляйте в GitHub учетные данные Mozilla, API-ключи и приватные ключи подписи.
