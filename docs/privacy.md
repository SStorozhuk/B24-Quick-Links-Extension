# Данные и приватность

Bitrix24 Quick Links работает локально в браузере пользователя и не использует внешний сервер расширения.

## Что хранится

- пользовательские блоки и ссылки;
- избранное;
- тема интерфейса;
- состояние блоков и кнопки «Открыть весь блок»;
- положение кнопки в левом меню;
- список активированных адресов Bitrix24.

Конфигурация ссылок, избранное и состояние блоков хранятся отдельно для каждого портала. Тема является общей настройкой расширения.

## Где хранятся данные

- Chrome, Edge, Яндекс Браузер и Firefox: локальное хранилище расширения;
- Safari Userscripts: локальное хранилище `GM.getValue` и `GM.setValue`.

В расширении нет аналитики, рекламы и сторонних трекеров. Разработчик не получает пользовательские настройки и историю переходов.

## Доступ к сайтам

Chromium- и Firefox-версии используют необязательное разрешение `https://*/*`, чтобы пользователь мог активировать любой облачный или коробочный портал. Это разрешение не дает расширению постоянный доступ ко всем сайтам автоматически.

Доступ к конкретному адресу запрашивается только после нажатия **Активировать на портале**. Перед запросом расширение проверяет наличие интерфейса Bitrix24 с левым меню. Разрешение сохраняется браузером для выбранного домена и может быть отозвано в настройках расширений.

Новые вкладки через фоновый процесс разрешено открывать только на том же HTTPS-домене, с которого поступила команда.

Safari Userscripts использует общий шаблон HTTPS, поскольку userscript не может динамически менять список доменов. Основной код запускается только после обнаружения интерфейса Bitrix24. Доступ Userscripts к сайтам регулируется настройками Safari.

## Импорт и экспорт

Экспортированный JSON содержит структуру ссылок и настройки интерфейса выбранного портала. Файл создается только по команде пользователя. Импорт выполняется из явно выбранного файла.

Если в ссылках присутствуют внутренние адреса или параметры, храните экспорт как рабочий конфигурационный файл и не публикуйте его без проверки.
