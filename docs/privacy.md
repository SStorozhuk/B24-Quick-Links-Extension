# Данные и приватность

Bitrix24 Quick Links работает локально в браузере пользователя.

## Что хранится

Расширение сохраняет:

- пользовательские блоки и ссылки;
- избранное;
- выбранную тему;
- состояние свернутых блоков;
- настройки кнопки «Открыть весь блок»;
- положение кнопки в левом меню.

## Где хранятся данные

- Chrome, Edge и другие Chromium-браузеры: локальное хранилище расширения;
- Firefox: `localStorage` соответствующего портала Bitrix24;
- Safari Userscripts: хранилище `GM.getValue` и `GM.setValue`.

Настройки не синхронизируются разработчиком и не отправляются на внешний сервер. В расширении нет аналитики, рекламы и сторонних трекеров.

## Разрешения

Доступ к страницам нужен для добавления кнопки в левое меню Bitrix24 и отображения панели быстрых ссылок. Готовая сборка ограничена доменами, перечисленными в манифестах и README.

Расширение не запрашивает доступ ко всем сайтам. Новые вкладки открываются только для разрешенных HTTPS-порталов Bitrix24.

## Импорт и экспорт

Экспортированный JSON содержит пользовательскую структуру ссылок и настройки интерфейса. Файл создается только по команде пользователя. Импорт выполняется из явно выбранного пользователем файла.

Если в ссылках присутствуют внутренние адреса или параметры, храните экспортированный JSON как рабочий конфигурационный файл и не публикуйте его без проверки.
