# Версия 1.0

Первый публичный выпуск репозитория Bitrix24 Quick Links Extension.

Готовые пакеты предназначены для поддерживаемых корпоративных порталов OSTEC и Selectica. Для другого коробочного портала используйте инструкцию [`../customization.md`](../customization.md).

## Пакеты

- ZIP для Google Chrome и Microsoft Edge;
- CRX3 для Яндекс Браузера;
- неподписанный XPI для Firefox Developer Edition.

## Проверка

- версия `1.0` установлена в манифестах Chromium и Firefox;
- JavaScript прошел синтаксическую проверку;
- тест фонового открытия вкладок пройден;
- ZIP и XPI соответствуют исходникам;
- подпись CRX3 проверена при сборке;
- контрольные суммы пакетов сохранены в `releases/1.0/SHA256SUMS`.

## Обновление 2026-10-03

- исправлено применение настроек свернутых блоков в Safari;
- исправлена видимость кнопки «Открыть весь блок» в Safari;
- поиск больше не держит в DOM скрытые копии исходных кнопок;
- удален блок заметок и связанный редактор форматирования;
- обновлены автоматические проверки сохранения настроек и повторного открытия панели.

## Поддержка доменов Selectica

- добавлены основной, тестовый и dev-порталы на домене `selectica.ru`;
- разрешения обновлены в Chromium и Firefox;
- Safari Userscripts пересобран для всех шести порталов;
- сохранена совместимость с прежними доменами `ostec-group.ru`.

## Подготовка к публичному доступу — 2026-10-24

- актуальные исходники и готовые пакеты для Chromium, Firefox и Safari сведены в один выпуск;
- подтверждено соответствие Chromium ZIP и Firefox XPI исходным каталогам;
- добавлены инструкции по установке, адаптации под другой портал и хранению данных;
- восстановлены инструменты сборки и проверки;
- локальные файлы macOS и приватные ключи исключены из репозитория.
