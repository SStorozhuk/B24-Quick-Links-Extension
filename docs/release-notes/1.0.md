# Версия 1.0

Первый публичный выпуск репозитория Bitrix24 Quick Links Extension.

## Пакеты

- ZIP для Google Chrome и Microsoft Edge;
- CRX3 для Яндекс Браузера;
- неподписанный XPI для Firefox Developer Edition.

## Проверка

- версия `1.0` установлена в манифестах Chromium и Firefox;
- JavaScript прошел синтаксическую проверку;
- тест фонового открытия вкладок пройден;
- ZIP и XPI соответствуют исходникам;
- подпись CRX3 проверена при сборке;
- контрольные суммы пакетов сохранены в `releases/1.0/SHA256SUMS`.
