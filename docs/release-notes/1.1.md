# Bitrix24 Quick Links 1.1.0

Дата подготовки: 25 октября 2026 года.

## Универсальные порталы

- удален обязательный список доменов из манифестов Chromium и Firefox;
- добавлена однократная активация открытого HTTPS-портала по значку расширения;
- перед запросом разрешения проверяется наличие интерфейса Bitrix24 с левым меню;
- динамические content scripts регистрируются отдельно для разрешенного адреса;
- фоновой процесс открывает вкладки только на домене страницы-отправителя.

## Конфигурация

- внутренние ссылки переведены на относительные пути текущего портала;
- добавлен базовый набор для новой установки: открытие по ID, CRM, работа, сотрудники и настройки;
- исключены корпоративные направления сделок, группы, списки, приложения и смарт-процессы с локальными ID;
- настройки ссылок, избранное и состояние блоков разделены по адресам порталов;
- сохранена общая тема интерфейса;
- добавлена миграция конфигурации `1.0` и импорт прежних JSON-файлов.

## Браузеры

- Chromium и Firefox используют `activeTab`, `scripting`, `storage` и необязательное разрешение на выбранный HTTPS-домен;
- Firefox получил фоновый процесс и единый слой хранения с Chromium;
- Safari Userscripts поддерживает произвольный HTTPS-домен и запускает основной код только после обнаружения Bitrix24;
- Safari также изолирует настройки по адресу портала и проверяет домен при открытии новых вкладок.

## Проверки

- тест универсальности манифестов и базовой конфигурации;
- тест активации произвольного облачного и коробочного домена;
- тест безопасности фонового открытия вкладок;
- тест окна активации;
- сборочный тест Safari;
- полный BX.UI smoke-тест, включая миграцию хранения.
