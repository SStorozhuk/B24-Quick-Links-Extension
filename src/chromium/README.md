# Chromium-сборка

Исходники версии **1.1.0** для Google Chrome, Microsoft Edge и Яндекс Браузера.

## Установка для разработки

1. Откройте страницу управления расширениями браузера.
2. Включите режим разработчика.
3. Выберите загрузку распакованного расширения.
4. Укажите папку `src/chromium`.
5. Откройте Bitrix24, нажмите значок расширения и активируйте текущий портал.

Для обычной установки используйте готовые пакеты из `releases/1.1/chromium`.

## Настройка ссылок

Основная конфигурация находится в `settings.js`. Внутренние ссылки задаются относительными путями. Пользовательские изменения сохраняются отдельно для каждого активированного портала и имеют приоритет над этим файлом.
