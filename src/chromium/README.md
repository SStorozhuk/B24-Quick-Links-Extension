# Chromium-сборка

Исходники версии **1.0** для Google Chrome, Microsoft Edge и Яндекс Браузера.

## Установка для разработки

1. Откройте страницу управления расширениями браузера.
2. Включите режим разработчика.
3. Выберите загрузку распакованного расширения.
4. Укажите папку `src/chromium`.
5. Обновите открытую страницу Bitrix24.

Для обычной установки используйте готовые пакеты из `releases/1.0/chromium`.

## Настройка ссылок

Основная конфигурация находится в `settings.js`. Пользовательские изменения, сделанные через редактор расширения, сохраняются в хранилище браузера и имеют приоритет над этим файлом.
