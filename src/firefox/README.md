# Firefox-сборка

Исходники версии **1.1.0** для Mozilla Firefox.

## Установка для разработки

Локальный XPI предназначен для Firefox Developer Edition с разрешенной установкой неподписанных дополнений. Обычный Firefox требует подпись Mozilla.

1. Откройте `about:addons`.
2. Выберите **Установить дополнение из файла**.
3. Укажите `releases/1.1/firefox/b24-quick-links-1.1.0-unsigned.xpi`.
4. Откройте Bitrix24, нажмите значок расширения и активируйте текущий портал.

Подробности постоянной установки приведены в `docs/firefox-signing.md`.

## Хранение

Firefox хранит пользовательские настройки в локальном хранилище расширения с отдельным пространством для каждого портала. Старые данные `localStorage` переносятся после первой активации прежнего адреса.
