# Safari Userscripts

Safari-версия состоит из двух файлов:

- `b24-quick-links-safari.user.js` — интерфейс, настройки, хранение и открытие вкладок;
- `b24-quick-links-bxui-safari.user.js` — мост к `BX.UI` страницы Bitrix24.

Оба файла собираются из актуальных исходников Chromium:

```bash
npm run build:safari
```

## Универсальные адреса

Метаданные используют `@match https://*/*`, потому что коробочный и облачный Bitrix24 могут работать на произвольном домене. На обычной HTTPS-странице скрипт проверяет признаки портала и немедленно завершает работу. Интерфейс и наблюдатели создаются только на странице Bitrix24 с левым меню.

## Установка

1. Установите Userscripts из App Store и включите расширение в Safari.
2. Откройте приложение Userscripts и посмотрите путь `Save Location`.
3. В Finder откройте этот путь и скопируйте в папку `scripts` оба `.user.js` из `releases/1.1/safari`.
4. Откройте нужный портал Bitrix24.
5. Разрешите Userscripts доступ к текущему сайту в Safari.
6. Убедитесь, что в меню Userscripts отображаются оба скрипта, и обновите страницу.

Скрипты сохраняются после перезапуска Safari и не требуют ежедневной переустановки.

## Хранение и ограничения

Настройки сохраняются через `GM.getValue` и `GM.setValue` с отдельным префиксом для каждого адреса портала. Новые вкладки открываются через `GM.openInTab` только на текущем HTTPS-домене.

Интерфейс `BX.UI` работает через отдельный page-context userscript, поскольку API `GM.*` доступны только в content-контексте Userscripts.

При закрытии панели ее DOM полностью удаляется. Во время поиска отображается только текущий набор результатов без скрытых копий исходных кнопок.
